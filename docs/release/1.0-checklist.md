# VJCraft 1.0 release checklist (macOS)

Target: macOS 1.0 (Apple Silicon, minimum macOS 12). Linux and Windows follow later as 1.x.
Path: `0.1.0-alpha.1` -> `1.0.0-beta.1` -> `1.0.0`.

State key: **done** (verified in repo or recorded result), **to test on hardware** (code exists, needs a real rig; see `docs/testing/hardware-test-guide.md`), **to do**.

A gate is passed only when every box for that stage is checked. Alpha -> beta needs the "Beta gate" items; beta -> 1.0 needs all items.

## Build, sign, notarize
- [x] **done** `scripts/package-macos.sh` builds `target/dist/VJCraft.app` and `VJCraft-<version>-macos.dmg`, bundles dylibs and the helpers (`vjc-clap-helper`, `vjc-ffgl-helper`). Beta gate.
- [x] **done** minos check: the script fails if any Mach-O in the bundle needs more than macOS 12.0; `LSMinimumSystemVersion` is 12.0.
- [x] **done** Developer ID signing with hardened runtime, notarization and stapling are implemented (`SIGN_ID`, `NOTARY_PROFILE`; `--no-notarize`, `--adhoc` for local builds).
- [ ] **to do** Run the full Developer ID + notarize path with the owner's Apple Developer account and keep the log. Beta gate.
- [ ] **to do** On a clean Mac (not the build machine): download the .dmg, open it, launch with no right-click workaround, confirm Gatekeeper accepts it. Update the README install step 3 (it still says ad-hoc, not notarized).

- [x] **done** Supervisor relaunches the child with `--child --recover` on crash (3 restarts in 60 s), panic hook writes `<data_dir>/crashes/`, watchdog writes `stall-*.txt`, helper processes isolated, fuzz corpus tests. See `docs/dev/reliability.md`.
- [ ] **to test on hardware** Force-kill the app during a show with output windows on a real LED wall: it relaunches, restores the project and reopens the screens on the same monitors (guide section a, step 14). Beta gate.

## Version bump plan
The version lives in one place: `version = "0.1.0"` at `Cargo.toml` line 8 (workspace). `scripts/package-macos.sh` reads it (line 26) and uses it for the .dmg name and `CFBundleShortVersionString` / `CFBundleVersion`. Other mentions: README ("Alpha release (v0.1.0)").
- [x] **done** Alpha: set `0.1.0-alpha.1` (notes: `docs/release/notes-0.1.0-alpha.1.md`); tag `v0.1.0-alpha.1` and the .dmg follow.
- [ ] **to do** Beta: after the Beta gate items, set `1.0.0-beta.1`, tag `v1.0.0-beta.1`.
- [ ] **to do** 1.0: set `1.0.0`, tag `v1.0.0`.
- [ ] **to do** At each bump: edit `Cargo.toml`, refresh `Cargo.lock`, update the README version line, package, check the .dmg name and the About/version string in the app.
- [ ] **to do** Check that `CFBundleVersion` accepts a pre-release suffix when notarizing; if not, derive a numeric build number in the script.
